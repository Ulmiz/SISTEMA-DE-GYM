Requerimientos para el Sistema del Gimnasio
Objetivo: Necesitamos un sistema web sencillo para la recepción. Lo importante es que sea rápido en horas pico, sin pantallas cargadas ni procesos largos.

1. Diseño de pantalla
•	 Que el estilo sea limpio, con botones grandecitos para Tablet o monitor
•	Colores que puede usar
o	Verde
o	Amarillo
o	Rojo
•	Fondo: Blanco  o gris claro para no cansar la vista.

2. Modulos que pedimos
•	Modulo 1: Registrar a los socios
o	Dar de alta, con nombre, teléfono, fecha de inicio, y tipo de pase  (Visita, Semanal, Mensual, Anual)
o	Que el sistema solo calcule fecha de vencimiento

•	Módulo 2: Mostrar pantalla como un dashboard
o	La pantalla donde trabajan diario.
o	Una lista rápida de colores como un semáforo 
o	Botón de "Cobrar" directo desde la lista








•	Módulo 3: forma de cobrar y los comprobantes
o	Registrar pago en efectivo o transferencia
o	Que genere un ticket básico con la fecha de vencimiento

•	Módulo 4: Corte de Caja
o	Que se vea el total cobrado de un solo día.
o	Desglose simple: Cuanto fue de visitas, mensualidades, y total por  el método de pago

•	Módulo 5: La forma en la que voy a acceder
o	Que haya un recepcionista, que pueda cobrar, registrar socios y ver la lista.
o	Administrador/Dueño: Único con permiso para cambiar precios, borrar datos o ver reportes globales. Que solo el pueda modificar precios, borrar datos o ver reportes globales

3. Condiciones de entrega
1.	Checar el estado de un cliente debe tomar máximo 2 clics.
2.	No se pueden guardar socios sin teléfono o nombre.
3.	El recepcionista no debe tener acceso a borrar registros ni cambiar precios.
